# Project 5 - Production Deployment & Support

## Objective
Deploy and verify a simple Python application
on a Linux server.

## Environment
- Oracle Linux 9
- Python 3
- Bash
- Git and GitHub

## Project Structure
- app/app.py - Production application
- scripts/deploy.sh - Deployment script
- logs/deployment.log - Deployment log

## Deployment
Run:

bash scripts/deploy.sh

Expected results:

Deployment started
Production application is running
Deployment completed

## Verification
The application was executed successfully
through the deployment script and the output
was captured in the deployment log.

## Troubleshooting
The deployment scripts was tested, the
application path was corrected, and the
deployment was re-verified successfully.

## Skills Demonstrated
- Linux application deployment
- Bash scripting
- Python application execution
- Log verification
- Basic production troubleshooting
- Git/GitHub
